DNS 设置教程

部分地区移动网络下无法访问部分网站，往往是运营商 DNS 解析不稳定所致。切换到公共 DNS 即可解决，以下是地址大全与各设备配置方法。

为什么要修改 DNS

同样的网站，电信、联通用户能正常打开，移动用户却打不开——很大几率是移动运营商的 DNS 服务器不及联通、电信稳定，导致域名解析失败。尝试改用公共 DNS 通常可以解决；如仍无法访问，可联系运营商官方客服。

1
进入系统设置页面，点击【无线和网络】。
2
在无线和网络页面中，点击【加密 DNS】。
3
选中【指定加密 DNS 服务】，在输入框填入 dns.alidns.com，保存即可。
不同品牌 Android 机型菜单略有差异，一般在「设置 → 网络 / WLAN → 私人 DNS 或加密 DNS」中可找到对应选项。
1
依次进入 「设置」→「无线局域网」，点击已连接 WiFi 右侧的 「i」 图标，拉到下方点击 「配置 DNS」。
2
将「自动」切换为 「手动」。
3
点击「添加服务器」，填入 223.5.5.5 与 223.6.6.6。
4
点击右上角「存储」完成设置。
1
选取苹果菜单 →「系统偏好设置」→「网络」。
2
左侧选择正在使用的网络（Wi-Fi 或以太网），点击右下角「高级…」。
3
切换到 DNS 选项卡，点击左下角 + 按钮添加 DNS 服务器。
4
填入 223.5.5.5、223.6.6.6，点击「好」→「应用」保存。
验证：在终端执行 nslookup，若返回 server 为阿里公共 DNS 即配置成功。
1
按 Win + I 打开设置，进入 「网络和 Internet」。
2
选择当前连接的网络（Wi-Fi 或以太网），找到 「DNS 服务器分配」，点击「编辑」。
3
将自动 (DHCP) 改为 「手动」，打开 IPv4 开关。
4
首选 DNS 填 223.5.5.5，备用 DNS 填 223.6.6.6，点击「保存」。
